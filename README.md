# 🗓️ Planora

Planora is a simple and intuitive task management web application that helps users organize their daily tasks, plan activities, and stay productive. The application provides a clean and user-friendly interface for creating, managing, and tracking tasks efficiently.

🌐 **Live Demo:** https://banditadas.github.io/planora/

---

## ✨ Features

* ➕ Add new tasks easily
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* ✏️ Edit existing tasks
* 📱 Responsive design for different screen sizes
* 🎨 Clean and modern user interface
* 💾 Stores tasks locally so they persist even after refreshing the page

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/BanditaDas/planora.git
```

### Navigate to the project folder

```bash
cd planora
```

### Run the project

Simply open `index.html` in your browser.

Or use VS Code's Live Server extension:

1. Open the project in VS Code.
2. Right-click on `index.html`.
3. Click **Open with Live Server**.
